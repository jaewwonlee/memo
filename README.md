# memo

`index.html`을 크롬에서 열면 바로 사용할 수 있는 키보드 전용 메모장입니다. 입력 내용은 같은 브라우저의 로컬 저장소에 자동 저장됩니다.

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 굵게 | `⌘ B` |
| 취소선 | `⇧ ⌘ X` |
| 밑줄 | 선택 후 `⇧ U` |
| 이탤릭 | 선택 후 `⇧ I` |
| 글자색 0–9 | 선택 후 `⌥ 0–9` |
| 배경색 0–9 | 선택 후 `⌥ ⌘ 0–9` |
| 왼쪽 정렬 | `⌃ ⌘ L` |
| 가운데 정렬 | `⌃ ⌘ E` |
| 오른쪽 정렬 | `⌃ ⌘ R` |
| 탭 / 목록 들여쓰기 | `Tab` |
| 목록 내어쓰기 | `⇧ Tab` |
| 여기까지 들여쓰기 표시 | `⌘ \` |
| 문단 나누기 | `Enter` |
| 문단 안 줄바꿈 | `⇧ Enter` |

`-` 또는 `1.` 뒤에 공백을 입력하면 목록으로 바뀝니다. 일반 글머리표에는 `•`만 표시되며, 번호 목록에서 `Tab`을 누르면 하위 단계가 `a.`, `b.`, `c.` 형식으로 표시됩니다.

`---`을 입력하면 구분선이 생깁니다. `#` 뒤에 공백을 입력하면 32px 제목이 되며, Enter를 누르면 일반 문단으로 돌아옵니다.

배경색이 적용된 영역을 다시 선택하고 같은 배경색 단축키를 누르면 배경색이 해제됩니다.

일반 문단의 Tab 간격은 4칸 단위의 탭 정지점입니다. 현재 위치에서 다음 4칸 경계까지 이동하므로 항상 공백 4개만큼 이동하는 것은 아닙니다.
